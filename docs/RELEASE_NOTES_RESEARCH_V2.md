# Research v2.0: Lifecycle Rules and Generic Companion Implementation

This research edition associates the version 2.0 working paper with the existing
generic companion implementation. The source repository and paper are associated
research materials; the English paper is the only file in the Zenodo update.

## Included

- English paper 2.0.
- Generic source and procedural assets from the existing application snapshot.
- Research overview, citation metadata, version history and exact PDF checksums.
- Separate paper/documentation and application/asset license scopes.

## Paper Changes

The historical lifecycle-design sequence remains the main case. A new generic
implementation section adds a four-direction client figure, a lifecycle rule
table, selected source correspondence and scoped software observations. The
paper distinguishes historical construction, later technical material and
future paired execution or owner-use research.

## Preserved Boundaries

Application version remains 0.1.0. This edition makes no production behavior,
generated-asset, world-data or client/server deployment changes. Application
license metadata now records MIT and CC BY 4.0. Existing test
results retain their recorded date and scope; the ear/tail geometry defect
remains open. The associated article is a retrospective design-case working paper.
