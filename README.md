# Companion Dog Framework

Private source-and-asset backup for Minecraft 1.21.1 / NeoForge 21.1.84, Java 21.
The current snapshot includes a procedurally generated default appearance and
its source generator. Personal photographs, predecessor artwork, identifying
case material and the predecessor's Git history are excluded.

The behavior code supports player binding, collar recall, home recovery after
lethal danger, delayed healing after ordinary damage, manual rest release,
bone interaction menus, feeding, procedural actions, and shared ball/disc fetch
claims. Ball and disc physics remain distinct.

## Appearance

The bundled grey-and-white default dog, entity textures, collar, ball and disc
assets are generated by `tools/generate_default_dog.py`. No reference image or
model file is consumed by that generator. `python tools/generate_default_dog.py
--check` compares the current 12 generated files with its outputs without
rewriting them. See [provenance and boundaries](docs/PROVENANCE.md).

`appearance-pack-template/` remains a deliberately empty external-pack template;
it is distinct from the bundled default. The spawn egg uses the game's built-in
template without redistributing that texture.

Use [the appearance contract](docs/APPEARANCE_CONTRACT.md) and
[the generation brief](docs/ASSET_GENERATION_BRIEF.md) for future asset creation.
Place completed packs in the client's resourcepacks directory. Reload resources
to rebuild the renderer. Packs change the appearance of all framework dogs on
that client; per-dog breed selection is not implemented.

## Verification

```powershell
./mod-build.ps1 build
pwsh -NoProfile -File tools/run-gametests.ps1
python tools/verify_public_boundary.py --jar build/libs/companiondog-1.21.1-0.1.0.jar
pwsh -NoProfile -NonInteractive -File tools/run-visual-tests.ps1 -ReloadOnly
```

Canonical build verifies the managed testing infrastructure, compiles Java,
runs JVM appearance-contract tests and checks that images match the generator.
Server GameTests exercise behavior without rendering dog assets. They do not
verify appearance or animation geometry. Every completed appearance needs a
fresh hidden-client visual test before visual acceptance.

The 13 October 2026 run passed all 52 server GameTests, 15 JVM tests, 10 static
asset tests and the 10-scenario resource-reload lane. The full client collected
98 frames but retained FAIL: ear/tail geometry penetrates the ground during
some roll-over/look combinations, up to 3.869217 model pixels. The author's
acceptance of the current art does not erase this finding. See
[the test report](docs/RESOURCE_RELOAD_TEST_REPORT.md). No full multiplayer or
universal breed-compatibility claim is made for this snapshot.

This namespace uses new entity, item and saved-data identifiers. It is not a
drop-in replacement or world migration tool for other companion mods.

## Publication Status

The author approved a new private remote backup, not public release. The original
private repository is untouched. Application metadata remains All Rights
Reserved; the proposed MIT code / CC BY 4.0 asset licenses are not granted by
this private-backup decision. Publishing code and granting reuse permission are
separate decisions. See [third-party notes](THIRD_PARTY_NOTICES.md).

The current canonical build verifies the author's private testing-infrastructure
release. Its installed code and agent instructions are intentionally excluded
from this backup; existing launchers retain the dependency and do not bypass
its gates. An authorized installation of that infrastructure is needed to
build/test this checkout through the existing launchers. Standalone Python
generator/static tests can run without it. Before a public reproducibility
claim, supply an authorized accessible distribution and anonymous clean-checkout
verification. Source availability alone does not establish that condition.
